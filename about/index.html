About fileforge

fileforge is a set of small converters for messy files: PDF tables that need to be in a spreadsheet, GPS tracks that need joining. Each one runs on your own device, so private documents never have to be uploaded anywhere.

fileforge is run by an independent developer. The converters are ordinary deterministic code: the same file always gives the same output.

Every converter is tested against synthetic sample files before each release. We never use customer files for testing; we never receive them.

fileforge is not affiliated with Microsoft, Adobe, Garmin, Strava, Intuit or Apple. Product names are used only to describe file formats.
