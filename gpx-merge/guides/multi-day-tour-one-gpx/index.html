Combine a multi-day tour into one GPX file, one segment per day

A bikepacking trip, a long-distance walk or a week of touring leaves you with one activity file per day. For a trip map or to share the whole route you want one file. Here is how to stack the daily files into a single GPX, with each day still separate inside it.

Verified sample Steps and sample produced by running this site's converter on synthetic files.

Steps

  1. Gather the daily files in one folder. FIT files straight from the device, GPX or TCX exports, or a mix. A day that ended with a flat battery can go in as it is: a FIT file cut short is repaired while it is read.
  2. Open the merge tool and tick "Keep each original segment separate". Leave "Convert each file to its own GPX" unticked; that option gives separate files instead of one. With it ticked, each day stays its own track segment. Without it, all days are joined into one continuous line, which draws a straight jump from each night's stop to the next morning's start.
  3. Select every day's file at once (Ctrl-click or Cmd-click in the file picker, or drag the whole selection onto the page). A new selection replaces the previous one, so add them all together.
  4. Leave the order to the tool. When every point has a timestamp, segments are put in order of their first point, so day 1 comes first whatever order the files arrived in. The tick box can be changed after the files are read; the result updates without reading them again.
  5. Check the summary. You should see one line per file with its point count, the number of segments (one per file for FIT files), and points in equal to points out unless two days overlapped.
  6. Download merged.gpx. The track is named "Merged track", or after the first named track found in a GPX or TCX input; rename it in your mapping app if you like.

Things to know

  • A GPX file that already has several segments keeps them all when the box is ticked, so the segment count can be higher than the number of files.
  • Waypoints in GPX inputs are kept (exact repeats once). Route points from a GPX route become track points.
  • Time, elevation and heart rate are kept; power, cadence and laps are not.
  • The output is one GPX file. If you want each day as its own GPX file instead, tick "Convert each file to its own GPX"; see converting many FIT files to GPX at once.
