Join a ride recorded in several parts into one track

You pressed stop at the café and forgot to restart, or the battery died and you started a new recording after charging. Now one ride is three activities. Here is how to turn the parts into a single track you can upload as one ride.

Verified sample Steps and sample produced by running this site's converter on synthetic files.

Steps

  1. Collect every part. Copy each activity file for the ride from the device (FIT) or export it from wherever it is stored (GPX or TCX). Mixed formats are fine. If one part was cut off by a dead battery, include it as it is: it is repaired while it is read.
  2. Open the merge tool, check that "Convert each file to its own GPX" is unticked (it is by default on this page), and drop all the parts in one go, or choose them together in the file picker. Dropping a second batch later replaces the first, so select them all at once.
  3. Don't worry about the order. When every point has a timestamp, the whole track is sorted by time. The page confirms this with "All points had timestamps, so the track is in time order". If it says instead that files were joined in the order you added them, some points had no timestamp, and the parts are joined in the order the browser handed them over; check the start and end of the result on a map before uploading.
  4. Check the counts line. It shows points in, points out and exact duplicates removed. Points out plus duplicates should equal points in, and the page shows a green "point count checks out" badge when it does. Duplicates appear where two recordings overlap: a point with the same position and the same time is kept once.
  5. Choose one segment or several. By default the parts become one continuous segment, which most sites treat as one unbroken ride; the gap while you were stopped stays a gap in time. Tick "Keep each original segment separate" if you want each part kept as its own segment inside the one track.
  6. Download merged.gpx and upload it as a new activity. If you had already uploaded the separate parts, remove them so the ride is not counted twice.

Things to know

  • Only exact duplicates are removed. If two devices recorded the same ride (a watch and a bike computer), their points differ slightly and both sets stay in: merge one device's files, not both.
  • The output is GPX 1.1 with time, elevation and heart rate. Power, cadence and lap markers are not carried over.
  • Distance and time totals are worked out by whichever site you upload to, from the points.
