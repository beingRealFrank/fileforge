Privacy

Your files never leave your device. Every conversion runs in your browser using code served from this site. The files you choose are read into your browser's memory, converted there, and handed back to you as a download. They are not sent to us or to anyone else, and they are gone when you close the tab.

How you can check

  • Each page sets a Content Security Policy that only allows connections back to this site and to Polar's license API (connect-src 'self' https://api.polar.sh). The license check, used only when you enter a key, sends the key and the number of pages or files used, never file contents.
  • The page loads no analytics, advertising or other third-party scripts.
  • Open your browser's developer tools, go to the Network tab, and convert a file: you will see no request carrying it.
  • An automated test runs each conversion in a real browser and fails if any request leaves the site or carries file contents.

This is evidence about the site as it is today, not a promise about every future version. If that ever changes, this page will say so first.

What is stored

  • Your browser's local storage keeps a count of pages converted today, used for the free allowance. It stays on your device.
  • The host (currently GitHub Pages) keeps standard web server logs such as IP address and pages requested, under its own privacy policy. We do not receive file contents in them.

If you buy a pack, Polar (our merchant of record) processes the payment and emails your key under its own privacy policy. Your browser stores the key locally so you don't have to paste it each time.

No accounts, no cookies for tracking, no email list.
