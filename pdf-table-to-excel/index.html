PDF tables → Excel or CSV

Drop one PDF or fifty. Each table row becomes a spreadsheet row, numbers become real numbers, and every file runs on your own computer. Nothing is uploaded.

How it works

  1. Your browser reads the text layer of each PDF with pdf.js, served from this site.
  2. Text is grouped into lines, and columns are found from the vertical gaps that run down the page.
  3. Every piece of text is checked off as it is placed in a cell. If anything is left over, the file is flagged so you know to look.
  4. You get one Excel workbook (a sheet per PDF, or one combined sheet) or CSV files.

Good for

  • Supplier invoices and price lists you need in a spreadsheet
  • Reports exported to PDF by software that has no CSV export
  • Many PDFs with the same layout that you want stacked into one sheet

Limits

  • Scanned PDFs (pictures of pages) have no text layer. They are detected and reported; OCR is planned.
  • A cell that wraps onto a second line is joined back into one cell when "table rows only" is on (with it off, each line is its own row). Check the preview.
  • Always check numbers before you import them into accounting software.

Privacy

The page loads no third-party scripts and its security policy blocks connections to other sites. Your files stay in your browser's memory and are gone when you close the tab. Details.
