Combine the line items from many PDF invoices into one sheet

A month of supplier invoices arrives as separate PDFs, and you need every line item in one spreadsheet to total, filter or reconcile. Here is how to stack them in one pass, with each row labelled with the invoice it came from.

Verified sample Steps and sample produced by running this site's converter on synthetic files.

Steps

  1. Put the invoices in one folder. This works best when they share a layout, for example all from the same supplier or the same billing system, so the columns line up. The file name becomes the label on every row, so a name with the invoice number in it is the most useful.
  2. Open the PDF table converter and leave "Skip titles and paragraphs (table rows only)" ticked. That drops the letterhead, addresses and notes, which sit on lines with only one piece of text, and keeps lines that have two or more cells.
  3. Tick "Combine all files into one sheet", then select all the invoices at once and drop them on the page. Each file is read in turn; the status line shows which one is being read.
  4. Check each file's card. Every invoice gets a preview with its page count, row count and column count. Look for the same column count on every invoice. A file with a different count has a different layout and its values will sit under different columns in the combined sheet. The green badge reads "all text placed", followed by how many characters of titles and notes (letterhead, addresses, footers) were left out. A yellow "check: some text not placed" badge means some text could not be accounted for; open that PDF and compare.
  5. Download Excel (.xlsx) or CSV. The combined sheet's first row is "Source file" followed by the first invoice's own column headings. When a later invoice starts with exactly the same header row, that row is dropped, so the headings are not repeated for every file.
  6. Look for odd headers. If a later invoice's header differs in any way (different wording or an extra column), it is not recognised as a header and stays in as a row; filter the SKU column for header text to find any.
  7. Reconcile before you rely on it. Sum the Amount column per source file and compare it with each invoice's total. Totals and subtotals printed under the table are included as rows if they sit on a line with two or more cells, so filter them out before summing.

Limits

  • PDFs that are scanned images have no text to read; the page reports them. OCR is not available yet.
  • A description that wraps onto a second line is joined back to its cell when the second line sits directly under the row and has nothing else on it, and "table rows only" is ticked. A wrapped line that shares its line with another wrapped cell, or sits further away, is not joined; check long descriptions against the PDF. A single line of text printed directly under the last row (a note such as "Prices include tax") is treated the same way and joined into that row's cell, so check the last row of each table.
  • Columns are found from the layout of each file separately, so invoices with different layouts do not line up in one sheet. Convert those as separate sheets (leave "Combine" unticked).
