Why a table copied from a PDF lands in one Excel column, and how to fix it

You select a table in a PDF, paste it into Excel, and every row arrives as one long line of text in column A, or the columns are shuffled. That is because a PDF stores text as positioned pieces, not as a table. Here is how to get proper columns without retyping.

Verified sample The sample below was produced by running this site's converter on a synthetic invoice PDF.

Why it happens

A PDF has no cells. Each word or number is placed at an exact position on the page. When you copy, the viewer guesses the order and joins the pieces with spaces, so Excel receives a line of text with no reliable separators. A converter has to rebuild the columns from where the text sits on the page.

Steps

  1. Check you can select the text. If you can highlight words in the PDF, it has a text layer and this works. If the PDF is a scanned picture of a page, you cannot select text, and OCR would be needed (not supported here).
  2. Open the PDF table converter and drop the PDF on it. It is read in your browser and not uploaded.
  3. Leave "Skip titles and paragraphs" ticked to keep only table rows, or untick it to keep every line of text.
  4. Check the preview. Each column of the PDF should be its own column. The page also checks that every piece of text was placed in a cell or reported as left out.
  5. Download Excel or CSV. Numbers arrive as real numbers, so totals and formulas work straight away.

When it will not work well

  • Tables drawn without a consistent column layout, or with merged cells across columns, may need a manual touch-up.
  • A cell wrapped onto two lines is joined back into one cell when table-rows-only is on; check long text cells in the preview.
  • Always check numbers before importing into accounting software.
