Convert a folder of FIT files to GPX in one go

You are moving years of rides to a new mapping app, archiving a device before you reset it, or sending a season's activities to someone whose software only reads GPX. Converting files one by one is slow. Here is how to convert the whole folder at once and get one GPX per FIT file.

Verified sample Steps and sample produced by running this site's converter on synthetic files.

Steps

  1. Copy the FIT files to one folder. On most devices that record FIT files they sit in an Activity folder when the device is connected by USB. Copy them off rather than working on the device.
  2. Open the FIT to GPX converter. Check that "Convert each file to its own GPX (download as .zip) instead of merging" is ticked; it is by default on this page. Unticked, the files are merged into one track instead.
  3. Select all the files at once (Ctrl-A or Cmd-A in the file picker, or drag the whole selection onto the page). A new selection replaces the previous one, so add everything in one go. GPX and TCX files can be mixed in; each still becomes its own GPX.
  4. Check the per-file list. Each file gets a line with its format and point count. A file that was cut off by a flat battery or a crash is marked "damaged file, recovered every complete record". A file that cannot be read at all is left out of the list and of the download, so compare the number of files listed with the number you selected. A file with 0 points has no GPS positions (an indoor workout, for example).
  5. Read the summary. In each-file mode it says how many files were converted and how many points they hold in total; every GPX keeps all of its own file's points.
  6. Download the .zip (gpx-files.zip). Each GPX has the same name as its FIT file with .gpx on the end. If two inputs have the same name, the second gets -2 added.
  7. Track names. FIT files carry no track name, so each converted track is named after its file (for example ride-part1). GPX and TCX inputs keep their own track name.

Things to know

  • Each GPX keeps latitude, longitude, time, elevation (when recorded) and heart rate. Power, cadence and laps are not carried over.
  • A single file is downloaded directly as a GPX, not a .zip.
  • Large folders are read one file after another in the browser tab, so keep the tab open until the list is complete.
