FIT file repair tools compared

A corrupt or truncated FIT file can often be repaired, and there are several tools that do it. This page compares them using what each tool's own page says, and says where the others do better than FileForge. FileForge is made by the person who runs this site, so read it with that in mind.

Where the others are better

  • Wrong timestamps. If Strava or Garmin complains about impossible or 1989 times, FileForge does not fix that. The5kRunner's free tool says it does, and FIT File Tools' Corrupt Time Fixer is the one Strava's help page on bad time data points to.
  • Hard cases. A desktop tool with a long history, such as Fit File Repair Tool, is aimed at files damaged in the middle. FileForge is built for files cut short at the end and says so when a file is beyond it.
  • Price. If you have one file and the free browser tool works, you do not need to pay for anything. FileForge's free allowance covers checking a file and converting it to GPX; the repaired .FIT download is the paid part.
  • Merging many files. GOTOES lists a merge tool with a 20-file limit and a free route for ordinary sizes.

Where FileForge fits

It runs in your browser, so the file is never uploaded, it shows in plain words what is wrong with the file before you change anything, and the repaired file keeps heart rate, power and laps recorded before the cut. It is tested on synthetic FIT files cut at several points, not on every device's files; if a repaired file is still refused by an app, open an issue and say which app.
