When a FIT file won't upload

A FIT file is a binary log the device writes as you go. If the battery dies or the unit freezes, the file is left without its final size and checksum, and most sites reject the whole thing. The data before that point is usually intact. This tool keeps every complete record, drops the half-written one at the end, rewrites the header size and both checksums, and adds a minimal session summary when none survived. You can download the result as a repaired .FIT, or as GPX. The page tells you when a file needed repair.

What it does

  • Reads every track point from GPX, TCX and Garmin/Wahoo-style FIT files, plus GPX route points and waypoints.
  • Damaged FIT files (cut off when a battery died or a device crashed) are repaired: every complete record is recovered.
  • If every point has a timestamp, sorts the whole track by time, so the order you drop files in doesn't matter.
  • Removes exact duplicates (same position and time), which appear when recordings overlap.
  • Keeps elevation, time and heart rate. Counts points in and out so you can see nothing was lost.

The merged file is standard GPX 1.1 and imports into Strava, Garmin Connect, Komoot and most mapping apps. fileforge is not affiliated with any of them.
