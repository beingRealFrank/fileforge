# fileforge

Small converters for messy files. They run in your browser: your files are processed on your own device and are never uploaded.
Site: https://beingrealfrank.github.io/fileforge/

## Tools
- [FIT repair and FIT to GPX](https://beingrealfrank.github.io/fileforge/fit-to-gpx/): check a FIT file for damage, download a repaired .FIT that keeps heart rate, power and laps, or convert to GPX. Handles files cut short by a flat battery.
- [Merge GPX, FIT and TCX](https://beingrealfrank.github.io/fileforge/gpx-merge/): join activity files into one track in time order, with exact duplicate points removed.
- [PDF tables to Excel or CSV](https://beingrealfrank.github.io/fileforge/pdf-table-to-excel/): batch-convert tables in PDFs to one workbook.
- [Bank statement to Excel or CSV](https://beingrealfrank.github.io/fileforge/bank-statement-to-excel/): turn statement PDFs into one transaction list with a running-balance check.

## Privacy
The pages load no third-party scripts, and their security policy blocks connections to other sites. The only request that can leave the page is the license-key check for paid packs, which sends the key and a usage count, never file contents. You can verify this in your browser's network tab.

## Free and paid
Free daily allowance: 5 PDF pages and 3 track files. A repaired .FIT download, and bigger batches, use paid credits (a one-time pack, valid 12 months). Payments are handled by Polar.

## Problems
This repository holds the built site only. Report a bad conversion or a bug in Issues and say which tool, and what you expected. Please do not attach files that contain private data.
